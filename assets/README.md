# Niani Kids — identité visuelle

Sources vectorielles éditables. Les personnages SVG sont des illustrations provisoires de cohérence UI et ne remplacent pas encore les rendus 3D officiels.

- `brand-logo.svg` : logo carré avec baobab souriant.
- `splash-screen.svg` : écran de lancement vertical.
- `characters/samba.svg`, `awa.svg`, `bobo.svg`, `baobab.svg` : personnages de référence.
- `scripts/generate-assets.mjs` : exporte les PNG nécessaires à Expo avec Sharp.

Les PNG sont générés par le workflow avant le build EAS. Les chansons enregistrées ne sont pas incluses : la lecture actuelle utilise la synthèse vocale.
