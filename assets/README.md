# Niani Kids — identité visuelle

Sources vectorielles éditables pour le logo, le splash et les quatre amis. Les PNG sont générés par `npm run assets` avec Sharp et intégrés à l'interface React Native. Les personnages actuels sont des illustrations vectorielles provisoires, pas les rendus 3D officiels.

- `brand-logo.svg` : logo de l’application.
- `splash-screen.svg` : écran de lancement.
- `characters/samba.svg`, `awa.svg`, `bobo.svg`, `baobab.svg` : sources des personnages.
- Les fichiers PNG générés sont des artefacts locaux et de CI.

Les chansons enregistrées ne sont pas incluses : la lecture actuelle utilise la synthèse vocale. Les paroles wolof doivent être validées par un locuteur natif.
