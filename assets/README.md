# Références visuelles Niani Kids

Les illustrations de référence déjà créées dans la médiathèque du projet sont :
- Logo circulaire Niani Kids d’Afrique.
- Logo 3D coloré Niani Kids sur fond transparent.
- Planche de personnages et fiches de référence 3D.
- Guide de style et guide de production coloré.
- Storyboard musical sénégalais et visuel « Bienvenue au village des Niani Kids ».

**Important :** ces références ne sont pas encore incorporées comme fichiers binaires dans le bundle mobile. Pour les intégrer, placer les exports optimisés dans ce dossier :
- `logo.png` : logo transparent pour l'en-tête.
- `logo-icon.png` : version lisible en petit format pour l'icône de l'application.
- `characters/samba.png`
- `characters/awa.png`
- `characters/bobo.png`
- `characters/baobab.png`
- `backgrounds/village.png` : arrière-plan du village.
- `backgrounds/baobab-grove.png` : arrière-plan du jeu.

Utiliser les PNG individuels avec transparence et les poses validées; éviter de recadrer une planche contenant plusieurs personnages pour les afficher comme s'il s'agissait d'images individuelles. Conserver les fichiers maîtres séparés et créer des versions compressées adaptées aux téléphones.
