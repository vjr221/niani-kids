# Niani Kids — assets visuels mobile

Les visuels originaux de la médiathèque ne sont pas encore présents dans le dépôt Git. Ne pas utiliser une capture d'une planche multi-personnages comme si elle était une illustration individuelle.

Fichiers attendus, exportés en PNG transparents et optimisés pour mobile :
- `logo.png` — logo transparent pour l'en-tête.
- `logo-icon.png` — icône carrée dédiée à Android/iOS.
- `characters/samba.png`, `characters/awa.png`, `characters/bobo.png`, `characters/baobab.png` — une image détourée par personnage.
- `backgrounds/village.png`, `backgrounds/baobab-grove.png` — décors pour accueil et jeux.

Avant de les référencer dans `require()`, vérifier que chaque fichier est réellement ajouté au dépôt. Cible recommandée : WebP/PNG optimisé, largeur 512–1024 px pour personnages, icône carrée 1024 px, transparence conservée.

## Qualité des personnages
- Samba : garçon, cheveux courts bouclés, sweat bleu.
- Awa : fille, longues tresses avec perles colorées, tenue d'inspiration sénégalaise.
- Bobo : garçon distinct, casquette rouge portée à l'envers, tee-shirt jaune.
- Baobab : personnage-arbre chaleureux, silhouette facilement reconnaissable.
