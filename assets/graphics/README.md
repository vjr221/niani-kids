# Bibliothèque graphique Niani Kids

Cette bibliothèque organise les visuels de marque reçus le 21 octobre 2026. Les originaux sont regroupés dans le paquet de transfert `Niani-Kids-bibliotheque-graphique-oct-2026.zip` fourni séparément, car les opérations de dépôt de texte seules ne permettent pas d'ajouter ces binaires PNG directement au dépôt.

## Arborescence cible

- `characters/samba/` — Samba, sweat bleu et cheveux courts bouclés.
- `characters/awa/` — Awa, longues tresses à perles multicolores et tenue à motifs.
- `characters/bobo/` — Bobo, casquette rouge à l'envers et tee-shirt jaune.
- `characters/baobab/` — mascotte Baobab.
- `logos/` — logo texte 3D, logo rond et variantes de marque.
- `banners/` — bannières web et réseaux sociaux.
- `brand/` — planches de présentation.

## Règles d'intégration

1. Conserver les originaux et leur provenance; ne pas écraser les fichiers maîtres par des versions compressées.
2. Ne pas utiliser une planche composite à la place d'un personnage individuel dans l'interface.
3. Vérifier la transparence réelle du logo : un damier visible peut faire partie des pixels.
4. Préparer des versions mobiles optimisées seulement après validation visuelle.
5. Le logo d'application doit être testé dans le masque rond/carré Android et sur fond clair/sombre.
6. Les images du lot sont des références approuvées pour le développement, mais toute bannière avec texte intégré doit être relue avant publication.

## État actuel

Le catalogue et le paquet d'originaux sont préparés. Les PNG doivent encore être copiés dans cette arborescence Git avant de pouvoir être importés comme modules locaux par React Native et inclus dans l'APK. Ne pas prétendre que ces originaux sont déjà embarqués dans l'application.
