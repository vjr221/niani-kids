# Niani Kids Child Theme

Theme enfant WordPress basé sur Twenty Twenty-Five. La page d'accueil est construite dans `front-page.php`, avec les styles dans `assets/niani-kids.css` et les interactions dans `assets/niani-kids.js`.

## Direction visuelle

- Identité crème, vert baobab et jaune soleil.
- Hero asymétrique avec scène 3D officielle Niani Kids, perspective CSS et animations légères.
- Sections éditoriales: chansons, contes, nature, jeu, personnages, apprentissage, coin des parents et réseaux sociaux.
- Menu mobile accessible, mission du jour interactive, filtres sans dépendance externe, prise en charge de `prefers-reduced-motion`.
- Aucune police distante ni bibliothèque d'animation lourde.

## Médias WordPress

Le modèle utilise les pièces jointes de la bibliothèque média du site Niani Kids:
- ID 10: logo rond
- ID 11: bannière officielle
- ID 12: activité nature / plantation
- ID 13: conte du Baobab
- ID 14: scène du Baobab pour le hero
- ID 15: Bobo
- ID 16: Bobo chante
- ID 17: Bobo joue au ballon
- ID 18: Awa

Samba utilise le fichier officiel `assets/Samba_vues_corps_entier.png` du thème.

## Déploiement

Préparer les changements sur la branche `site/wordpress-child-theme`, vérifier PHP et le rendu, puis déployer sur le site. Ne pas fusionner dans `main` sans autorisation explicite. Ne jamais modifier ni désactiver Novamira.
